# Optional login background video

Put a video named `login-bg.mp4` (or `login-bg.webm`) in this folder to play it behind the
sign-in card instead of the animated CPR scene. Keep it short (10–30 s, it loops), silent,
and small (under about 10 MB; 720p is enough). It is bundled with the dashboard, so it works
offline. The launcher rebuilds the dashboard automatically the next time L.I.F.E. starts.

Use only footage you have the rights to and, if people appear in it, their consent.
